### Hi, I'm Mark 👋

I've shoved a microphone into a beehive while wearing khaki shorts, interviewed the creator of *Evil Bong 3D*, and worked *Laverne & Shirley* into a segment about Milwaukee beer commercials. It's an eclectic clip file — alt-weeklies, science communication and a long run producing digital for [*To The Best Of Our Knowledge*][ttbook].

Now I'm a digital content editor for [PBS Wisconsin][pbswi], and I moonlight for [Wonder Cabinet][wc].

In 2009, keeping up meant learning Premiere and Lightroom between journalism classes. Today it means running a fleet of AI coding agents. I think disclosure is super important — look for the `Co-Authored-By` trailers — and I try to use AI tools to learn how to build things I used to only be able to imagine.

### Things I've built

- [Cardigan][cardigan] — an exploration of how much juice you can get simply by having a caption file for a piece of content. Agentic pipeline that helps with everything from generating formatted transcripts to analyzing metadata to brainstorming and fact-checking titles and copy.
- [Podcast Publishing Suite][pps] — make one digital producer feel like 20.
- [Quick PARA][qp] — an Obsidian plugin that automates the PARA method.
- [Web Tools][wt] — browser-based tools for cleaning up HTML markup, because if you edit content for the web, you spend a LOT of time copy-pasting stuff between browser windows.

If you have a new media puzzle, I'm game to brainstorm. More at [bymarkriechers.com][site].
